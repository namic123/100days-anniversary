# 별자리 인트로 미디어 가이드

## 폴더 구조

```text
src/assets/intro-media/
├── photos/
│   ├── media-01.webp
│   ├── media-02.webp
│   ├── ...
│   └── media-12.webp
└── video/
    └── media-13.mp4
```

파일이 없으면 현재 가상 이미지가 그대로 표시된다. 파일을 정확한 이름으로 추가하면 Vite가 해당 파일만 자동으로 빌드에 포함하고 별자리 인트로의 지정된 슬롯에 사용한다. 개발 서버가 실행 중이었다면 새 파일을 추가한 뒤 서버를 다시 시작한다.

## 파일 준비 규칙

- 사진은 WebP 형식을 사용한다.
- 사진 한 장은 가능하면 `100-300KB` 정도로 최적화한다.
- 세로 사진은 카드의 `object-fit: cover` 규칙에 맞춰 중앙을 기준으로 잘린다.
- 영상은 MP4, 무음 자동 재생 기준으로 준비한다.
- 사진과 영상에서 EXIF와 위치 정보를 제거한다.
- GitHub Pages에 배포되는 모든 미디어는 URL을 아는 사람이 접근할 수 있다.
- 실제 개인 미디어를 커밋하기 전 화면 배치와 공개 범위를 다시 확인한다.
